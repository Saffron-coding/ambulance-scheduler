Ambulance Scheduler

The Ambulance Scheduler is a web application designed to manage ambulance jobs efficiently. Users can create, view, update, and delete ambulance job records through a simple and intuitive interface.

The system provides a structured way to store and manage job data such as location, category (priority), timing, and outcomes.

This application further includes a scheduling and optimisation engine, which will automatically assign ambulances to jobs based on availability, priority, and timing constraints.

Navigate the system

View Jobs — view all ambulance jobs currently stored in the system.

Create Job — add a new ambulance job to the system.

View Scheduled Jobs — View all scheduled and awaiting jobs.

View Ambulances — see all ambulances currently available in the system.

Create Ambulance — add a new ambulance resource for scheduling.
